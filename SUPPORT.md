# Getting help

Trama is in alpha and answers are best effort. Here is where to go:

- **How to use or run Trama.** Start with the [README](README.md), then [CONTEXT.md](CONTEXT.md) for the vocabulary. Most documents in `docs/` are in Italian.
- **Questions and ideas.** Use [GitHub Discussions](https://github.com/emanueledenaro/trama/discussions), or open an issue with the **Domanda** template.
- **Bugs.** Open an issue with the **Bug** template. Say which version or commit, operating system and provider you use.
- **Feature requests.** Open an issue with the **Richiesta di funzione** template and describe the problem before the solution.
- **Security problems.** Never in public: follow [SECURITY.md](SECURITY.md).
- **Contributing.** See [CONTRIBUTING.md](CONTRIBUTING.md).

Issues are written in Italian, as described in [AGENTS.md](AGENTS.md).

Problems with a provider account, quota or sign-in belong to that provider's support, since Trama uses each provider's official CLI and does not manage credentials.
