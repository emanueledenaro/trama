# Issue tracker: GitHub

Le attività di Trama vivono nelle GitHub Issues di `emanueledenaro/trama`. Usare `gh` con `--repo emanueledenaro/trama` quando il remote locale non è disponibile.

Leggere una issue con `gh issue view <numero> --comments`. Creare una issue con `gh issue create --title <titolo> --body-file <file>`, solo nel perimetro autorizzato dall'utente. Per testi su più righe usare file con newline reali.

Tenere distinti stato del lavoro, verifiche, commit locale, push e chiusura dell'issue. Chiudere un'attività solo quando i suoi criteri sono verificati.

PRs as a request surface: no.
