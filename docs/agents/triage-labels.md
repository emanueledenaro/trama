# Etichette di triage

| Ruolo | Etichetta |
| --- | --- |
| Da valutare | `needs-triage` |
| Informazioni mancanti | `needs-info` |
| Pronta per un agente | `ready-for-agent` |
| Richiede intervento umano | `ready-for-human` |
| Non prevista | `wontfix` |

La mappatura usa i nomi predefiniti delle skill. La creazione di etichette remote segue il perimetro della richiesta corrente.
